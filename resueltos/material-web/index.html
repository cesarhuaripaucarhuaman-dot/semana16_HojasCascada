Los <md-*> traen la animación, el ripple y la accesibilidad. El color y la tipografía siguen viniendo de nuestros tokens.

Servidor local

Sin servidor,
no hay componentes.

Los módulos no se cargan desde file://. Desde la raíz del proyecto, en CMD o Git Bash: 

npx http-server -p 8080

Luego abre http://localhost:8080/resueltos/material-web/ y navega hasta esta página. Para detener el servidor, Ctrl + C.

Componentes: esm.run/@material/web · carga por red, requiere internet.

  1. 01

    Sin framework

    Cada md-* es un elemento personalizado. El importmap le dice al navegador de dónde bajarlo.

  2. 02

    Tema propio

    Los --md-sys-color-* apuntan a tokens.css, así que el modo oscuro también alcanza a los componentes.

  3. 03

    Detalles incluidos

    Ripple, foco visible y estados de error vienen resueltos. Nosotros solo damos los valores de marca.
