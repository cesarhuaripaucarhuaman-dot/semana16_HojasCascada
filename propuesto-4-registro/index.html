Cómo está hecho

Componentes ajenos,
sistema propio.

Material Web trae el comportamiento; los colores y la tipografía siguen saliendo de tokens.css.

  1. 01

    Importmap, sin build

    Los componentes se cargan como módulos ES desde un CDN. No hay npm install ni paso de compilación.

  2. 02

    Tokens mapeados

    Los --md-sys-color-* apuntan a nuestras variables, así que el modo noche también funciona aquí.

  3. 03

    El diálogo devuelve el foco

    md-dialog se abre con show() y, al cerrarse, regresa el foco al botón que lo lanzó.

<script type="importmap">
  { "imports": { "@material/web/": "https://esm.run/@material/web/" } }
</script>
